# Powering on

press and hold the power button for about 1–2 seconds. Once powered on, the screen and system interface will appear automatically.

![Power On](/images/power-on.png "Power On")

<Warning>
  Press and hold the power button for about 4–5 seconds. The screen will turn off automatically once the device has powered down.
</Warning>

# Rebooting

You can reboot the device from the system interface or directly through the GPIO header.

## Software reboot

![Software Reboot](/images/Software-reboot.png "Software Reboot")

Once the device is powered on, go to `Advanced` > `System`, then tap `Reboot`. The device will restart automatically.

## Hardware reboot

![Rebooting](/images/rebooting.jpg "Rebooting")

Briefly short the `RESET` and `GND` pins on the GPIO header with a jumper wire or Dupont pin. The device will restart immediately.

# **SD Card Insertion**

Make sure a microSD card is inserted into your MeowKit before using storage-related features or updating firmware. The microSD card is used to store apps, assets, configuration files, media, logs, and other user data.

MeowKit supports FAT16 and FAT32 file systems and is compatible with most microSD / microSDHC cards. For the best compatibility and performance, we recommend using a standard 8–32 GB FAT32-formatted microSD card.

Higher-capacity cards may require longer initialization times and can vary depending on card quality and formatting. If the card is not recognized properly, please reformat it to FAT32 before use.

![SD Card Insertion](/images/SD-Card-Insertion.png "SD Card Insertion")
