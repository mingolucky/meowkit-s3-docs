# MCU

- Model: ESP32-S3-WROOM-1-N16R8
- CPU: Xtensa® 32-bit LX7 Dual-core, up to 240 MHz
- Wireless: 2.4 GHz Wi-Fi (802.11 b/g/n), Bluetooth 5.0 LE (Mesh supported)
- Memory: 512 KB internal SRAM, supports 8 MB external PSRAM
- Flash: 16 MB

# Audio

**Input**

- ADC: ES7210
- Microphone: ZTS6216 (Digital MEMS mic)

**Output**

- Amplifier: NS4150B, Class-D, 1 W
- Speaker: 1W 8Ω speaker with 1.25mm connector

# GPIO

1×16-pin (2.54 mm) Dupont female expansion header

![MeowKit-S3 GPIO header pinout](/images/GPIO.png "GPIO")

**External Power:**

  Pin 1: 3.3 V

  Pin 2: GND

  Pin 3: 5 V / VBUS

**I²C:**

  Pin 4: SDA (1 kΩ optional pull-up)

  Pin 5: SCL (1 kΩ optional pull-up)

**SPI:**

  Pin 6: CS0 (EXP\_IO2)

  Pin 7: MOSI (GPIO11)

  Pin 8: MISO (GPIO10)

  Pin 9: SCLK (GPIO9)

**Multi-function:**

  Pin 10: GPIO44

  Pin 11: GPIO12 / U

  Pin 12: GPIO17 / L /PWM

  Pin 13: GPIO18 / D / ADC

  Pin 14: GPIO8 / R / INT

Pin 15: RESET (hardware reset)

Pin 16: GND
