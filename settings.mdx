# Date & Time

Set the date and time manually whenever needed. MeowKit saves your changes to its real-time clock (RTC), so time continues to run while the device is powered off.

**Choose what to set**

![MeowKit-S3 Clock Settings menu](/images/CLOCK_SETTINGS_IMAGE.png "CLOCK SETTINGS IMAGE")

The **Clock Settings** screen provides two options: **DATE** and **TIME**. **DATE** is selected by default.

Tap an option, or move left and right with the joystick. Press **A** to open the selected setting. Press **B** to return to the Clock screen.

## Set Date

![Setting the date on MeowKit-S3](/images/SET_DATE_IMAGE.png "SET DATE IMAGE")

Use the three-column picker to set the date:

- M — Month, from JAN to DEC
- D — Day, from 01 to 31
- Y — Year, from 2024 to 2035

The current date is loaded automatically when you open this screen. Scroll each column to make your selection, then press A to save the new date. A brief Saved message confirms the update.

Press B to return without saving.

## Set Time

![Setting the time on MeowKit-S3](/images/SET_TIME_IMAGE.png "SET TIME IMAGE")

Use the three-column picker to set the day and time:

- W — Day of the week, from SUN to SAT
- H — Hour, from 00 to 23
- M — Minute, from 00 to 59

The current day and time are loaded automatically. Scroll each column to adjust the value, then press A to save. The new setting takes effect immediately.

Press B to return without saving.

# WLAN Setup

WLAN Setup lets MeowKit find, join, and remember Wi‑Fi networks.

![MeowKit-S3 WLAN network setup screen](/images/WLAN_SETUP_IMAGE.png "WLAN SETUP IMAGE")

## Scan and connect

MeowKit scans for nearby networks when you open this page. Use the switch in the upper-right corner to stop or start scanning. Networks are ordered by priority: connected first, then saved networks, then other networks by signal strength. Each row shows the network name and signal percentage:

- Green — strong signal
- White — usable signal
- Gray — weak signal
- Saved — network details are stored
- Open — no password required
- Lock icon — password required
- Checkmark — currently connected Select a network to connect:
- Saved network — reconnects with the saved password
- Open network — connects directly
- Secured network — opens the password keyboard If no network appears, select Rescan.

## Password keyboard

Use the multi-tap keypad to enter a Wi‑Fi password. Press a letter key repeatedly to cycle through its letters. Use the layout switch key to cycle through:

- abc — letters; use Shift for uppercase

![MeowKit-S3 Wi-Fi password letter keyboard](/images/keyboard_abc.png "Keyboard Abc")

- 123 — numbers

![MeowKit-S3 Wi-Fi password number keyboard](/images/keyboard_123.png "Keyboard 123")

- Symbols — password symbols

![MeowKit-S3 Wi-Fi password symbol keyboard](/images/keyboard_symbols.png "Keyboard Symbols")

The top field shows your input. Use **X** to delete the last character. Select **Send** to connect.

Passwords must contain at least eight characters. If the password is wrong, MeowKit tells you and lets you try again.

## Forget a network

Press and hold a saved network, then choose **Forget Network** to remove its saved details.

# Advanced

Advanced is where MeowKit keeps the controls that matter. Display, sound, connections, time, and system maintenance—clear, close, and ready when you need them.

Open **Advanced** from **Settings** by selecting the detailed settings button.

![MeowKit-S3 Advanced Settings screen](/images/ADVANCED_SETTINGS_IMAGE.png "ADVANCED SETTINGS IMAGE")

## Navigate

The left side of the screen lists five sections: Display, Sound, Connect, Time, and System. The right side shows the selected section. Use the touchscreen to select a tab, or press Up and Down to move between sections. The System tab can scroll vertically.

- A — Return Home
- B — Return to Settings

## Display

Make the screen comfortable to read, and the LED comfortable to live with.

**LCD Backlight**

Adjust the screen backlight with the slider. The displayed value ranges from 0% to 100%.

MeowKit keeps a 20% minimum backlight level. The screen will not go completely black by accident.

**LED Indicator**

Adjust the overall brightness of the built-in WS2812B LED from 0% to 100%.

This changes brightness only. Your selected LED color and effect stay as they are.

## Sound

Set the volume. Keep the feedback you want.

**Speaker Volume**

Adjust speaker volume from 0% to 100%. Changes take effect immediately. MeowKit keeps output within the speaker’s safe operating range.

**Key Tone**

Turn button feedback sound on or off.

## Connect

See what MeowKit remembers, and choose what it should use.

**Bluetooth**

Turn Bluetooth on or off. MeowKit saves this preference for future startup.

**Wi‑Fi**

Turn Wi‑Fi on or off. Wi‑Fi network setup is managed from the dedicated Wi‑Fi page.

**SSID Status**

This row shows the saved Wi‑Fi name and current connection state.

- Connected — MeowKit is connected.
- Not connected — A network may be saved, but MeowKit is not connected now.
- --- — No Wi‑Fi network has been saved.

## Time

Time stays visible, so you do not have to guess.

The current date and time refresh every second.

Choose **Set Date** to change the date. Choose **Set Time** to change the day of week and time. Your changes are saved to MeowKit’s real-time clock.

## System

System shows the state of your MeowKit and provides the tools to maintain it.

**Battery**

View live battery percentage and charging status. The battery indicator changes color when charging or when power is low.

**Reboot**

Select **Reboot** to restart MeowKit immediately.

A restart closes running tasks and starts the system again. Your saved settings remain intact.

**Storage**

View microSD card usage at a glance.

The orange bar shows used capacity. Capacity is shown as used space over total space. If no card is available, MeowKit shows `not mounted`.

To transfer files, return to **Settings** and open USB Mass Storage mode.

**NVS Config**

View usage of MeowKit’s internal settings storage.

**Factory Reset**

Factory Reset clears saved settings and restarts MeowKit.

This includes display brightness, volume, LED preferences, Bluetooth preferences, Wi‑Fi details, and other stored settings. MeowKit asks for confirmation before it resets.

This cannot be undone. If one setting is wrong, adjust that setting instead.
